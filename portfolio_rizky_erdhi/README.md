# Portfolio Rizky Erdhi Wijaya

Website portofolio mahasiswa Teknik Informatika dengan fokus Full-stack Web Development.

## Cara menjalankan
1. Ekstrak folder dari file ZIP.
2. Buka `index.html` di browser, atau gunakan ekstensi Live Server di Visual Studio Code.
3. Edit konten pada `index.html` dan desain pada `style.css`.
4. Interaksi menu navigasi mobile ada di `script.js`.

## Sebelum dipakai melamar magang
- Ganti `emailkamu@example.com` dengan email aktif.
- Ganti tautan GitHub dan LinkedIn dengan akun asli.
- Pastikan teknologi pada bagian keahlian benar-benar pernah dipelajari.
- Bagian proyek saat ini adalah RENCANA PROYEK, bukan proyek yang sudah selesai. Bangun proyeknya, tambahkan screenshot, lalu tautkan repository/demo.
- Tambahkan CV PDF setelah CV selesai dibuat. Tombol unduh CV belum ditampilkan karena file CV belum tersedia.

## Struktur
- `index.html` — isi dan struktur website
- `style.css` — tampilan responsif
- `script.js` — interaksi menu navigasi
